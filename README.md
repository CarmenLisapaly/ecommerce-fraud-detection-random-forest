# E-Commerce Fraud Detection using Random Forest

## Overview
This project develops a machine learning pipeline to detect fraudulent e-commerce transactions using Random Forest.

## Features
- Data preprocessing
- Exploratory Data Analysis (EDA)
- Feature engineering
- SMOTE for class balancing
- Random Forest classifier
- Model evaluation
- Manual fraud prediction

## Dataset
- **Name:** Fraudulent E-Commerce Transactions
- **Source:** Kaggle
- **Dataset Type:** Synthetic e-commerce transaction dataset
- **Link:** https://www.kaggle.com/datasets/shriyashjagtap/fraudulent-e-commerce-transactions

## Technologies
- Python
- Pandas
- NumPy
- Scikit-learn
- Random Forest
- SMOTE
- Matplotlib
- Seaborn

## Results
- Accuracy: 83.44%
- Fraud Recall: 61%
